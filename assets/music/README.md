# K-Pop Demon Hunters — Soundtrack Folder (`assets/music/`)

The game includes built-in synthesized K-Pop arcade loops out of the box, **and** it automatically detects and streams your real `.mp3`, `.ogg`, `.wav`, or `.flac` song files when you drop them into this folder!
